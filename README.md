# Eclipse Macros for Geometry Dash 2.2081

This page has macros for Eclipse mod on Geode, Choose a gdr2 file, go to the search on your task bar, type in "%LocalAppData%\GeometryDash\geode\mods\eclipse.eclipse-menu\replays", then enter it, After entering it, place the GDR2 file in there.

Required mods :
https://geode-sdk.org/mods/eclipse.eclipse-menu

> [!IMPORTANT]
> **Required Settings:** All macros in this repository require exactly **240 FPS** to run properly, if your computer cannot run at 240fps, then it will be **impossible!**
